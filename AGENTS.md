# Project rules

Preserve relaxed, hold-to-mine gameplay. Keep rules independent of Three.js, DOM, audio, and animation. Presentation never awards resources. Tune values in src/game/rules.js. Use no user data or unrelated game source. Run node --test tests/*.test.js after rule changes and browser-check mining, collision, pause, shop, and saving after integration changes. Record limitations honestly. Do not introduce multiplayer, payments, analytics providers, or prestige without a scoped decision.
